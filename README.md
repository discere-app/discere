# Discere

Discere is a Flutter flashcard app (Android + iOS) for learning marine life and biological species. Users build or import species decks and review them using the **FSRS 6** spaced-repetition algorithm. The app supports offline use, push notifications for due reviews, deck sharing (QR / JSON / text), and DE/EN localization.

## Developer Setup

### 1. Prerequisites

Ensure you have a complete Flutter development environment set up:

```sh
flutter doctor -v
```

### 2. Get Dependencies

```sh
flutter pub get
```

### 3. Generate Code

The project uses code generation for localization, JSON serialization, and test mocks. Run both commands after cloning, and re-run the relevant one after changing `.arb` files, `@JsonSerializable` models, or `@GenerateMocks` annotations:

```sh
flutter gen-l10n                                          # localization
dart run build_runner build --delete-conflicting-outputs  # JSON serialization + test mocks
```

### 4. Generate Assets (Optional)

Only needed when splash screen or launcher icons change:

```sh
dart run flutter_native_splash:create  # splash screen
dart run flutter_launcher_icons        # launcher icons
```

### 5. Run the Application

```sh
flutter run
```

## Running Tests

```sh
flutter test                                       # all unit tests
flutter test test/service/decks_service_test.dart  # single test file
flutter test integration_test/                     # integration tests (requires device/emulator)
flutter analyze                                    # lint
```

## ETL Pipeline

The reference database (`discere_reference.db`) is generated by a standalone ETL pipeline in [`etl/`](etl/) (bash + DuckDB + SQLite). It is not part of the Flutter build. See [`etl/README.md`](etl/README.md) for details.
